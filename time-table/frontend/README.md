## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `src/app/page.tsx`. The page auto-updates as you edit the file.

---

## 📜 Key Pages

- **Course Catalog (`/catalog`):** [http://localhost:3000/catalog](http://localhost:3000/catalog) — Full-text search and department filters.
- **Manual Builder (`/builder`):** [http://localhost:3000/builder](http://localhost:3000/builder) — Section picker with real-time visual conflict detection.
- **Auto-Generator (`/generator`):** [http://localhost:3000/generator](http://localhost:3000/generator) — Microsecond backtracking engine with soft-preference sliders.
- **Saved Schedules Dashboard (`/dashboard`):** [http://localhost:3000/dashboard](http://localhost:3000/dashboard) — Saved schedules dashboard with `.ics`, PNG image, and PDF exporters.
- **Admin Ingestion (`/admin/ingestion`):** [http://localhost:3000/admin/ingestion](http://localhost:3000/admin/ingestion) — Master Excel spreadsheet upload interface.
